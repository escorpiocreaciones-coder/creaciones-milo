LEEME — EDITOR DE PLANTILLAS (Creaciones Milo)
========================================================

QUÉ ES
Un editor sencillo para personalizar las plantillas (árbol, espacio,
polaroids, línea del tiempo, cartas, cápsula) con los datos de cada
pedido: nombres, fechas, mensajes, fotos y la canción.

CÓMO EMPEZAR
1. Abre editor.html (doble clic).
   Si el navegador pide "elegir archivo", elige el archivo .html de la
   plantilla que quieras usar (ej. arbol.html) y continúa igual.
2. A la izquierda aparecen los campos: nombres, años que abarca y una
   tarjeta por cada recuerdo (título, fecha, mensaje y foto).
3. Fotos: cada recuerdo puede:
   - quedar vacío  -> se muestra un cuadro de colores con iniciales
   - tener URL     -> pega el enlace de la foto
   - subir archivo -> botón "Archivo" (la foto queda DENTRO del archivo)
4. Puedes subir varias fotos a la vez con el botón "Subir varias fotos
   a la vez".
5. Canción: en la parte de abajo, "Canción de fondo". Sube el audio que
   pidió el cliente. Si no hay canción, la página no muestra botón.
6. A la derecha está la VISTA EN VIVO con el resultado: toca las cosas
   como si fueras el cliente (abrir, voltear, mirar...).
7. Cuando esté listo: botón "Descargar página lista". Sale un archivo
   como "arbol-ana-luis-2021-2026.html". Ese archivo es el pedido.

CÓMO ENTREGARLO
- Rápido: envíale el ARCHIVO al cliente por WhatsApp (Documento) y se
  abre con un toque.
- También puedes subirlo a Google Drive y compartir el enlace.
- Limpio: pídenoslo a Creaciones Milo para ponerlo en la web y entregar
  un enlace limpio directo.

SI ALGO SALE MAL
- El editor guarda un borrador automático mientras editas la plantilla.
  Si cierras la pestaña, al volver a abrir la MISMA plantilla aparece
  el borrador otra vez.
- "Nuevo pedido" borra el borrador de esa plantilla y empieza limpio.
- "Abrir un pedido anterior" permite re-editar un archivo ya entregado.

ANTES DE ENTREGAR
- Revisa la vista en vivo con calma, como si fueras el cliente.
- Si la página queda muy pesada (muchas fotos o una canción larga),
  verás un aviso con el peso en KB abajo.
